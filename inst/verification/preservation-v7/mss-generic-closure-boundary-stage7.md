# Generic normalizer proof-closure boundary: stage 7 design evidence

This is a read-only boundary assessment following the frozen `9ece`/`f293` review, not acceptance of an implementation-7 candidate. Earlier review reports remain unchanged. All new fixtures are private under `review-mss-multiallelic-reanchored-stage6/`; no production source, library, live preparation or cloud state was changed.

**Mapping selection and ambiguity evidence need separate pools.** Let M be the original coordinate/ID-intersection candidate pool, whose selection/count semantics are retained. Let P be the completed eligible proof closure: all input-ID and coordinate-derived identities, their current-ID events, and exact-event C bridges to connected current IDs, iterated to a bounded fixed point. Define REF–ALT interpretation identity by `(canonical event, swapped, complemented)`, not by the spelling of an ID. A selected single main interpretation h can be accepted only if P has neither a distinct REF–ALT interpretation nor a coherent ALT–ALT witness. Do not promote proof-only mappings merely because the original pool has no selected interpretation. Raw lookup caps and an explicit whole-closure resource bound must refuse incomplete proofs, rather than accept an arbitrary prefix.

The minimal fixed-point REF–ALT counterexample is FASTA `AAAAA` with rows:

```
position 1  A -> G  ID r
position 1  A -> G  ID q
position 3  A -> G  ID q
```

Source ID `r`, missing position, `A/G` has only position 1 in M. The exact-event C bridge adds q, and I:q adds position 3 to P. All S contexts are biallelic, so an ALT–ALT-only proof check cannot detect the second REF–ALT identity. The current native output selects position 1; ID q already gives ambiguity. Under the proposed expanded closure universe, r and its historical aliases must also remain ambiguous while candidate_count can remain |M|=1. Known source position 1 remains a valid control. Exact four-row input/output: `closure-refalt/`.

The single-base finite-anchor proof remains valid after expansion, but must quantify over **all P**, not only M. Two distinct concrete single bases cannot trim/reanchor under REF–ALT normalization, so the canonical position of every eligible SNP candidate is its only possible source anchor. Known source coordinates further restrict those anchors. Multiple primary IDs for one identical event/orientation do not constitute multiple biological hypotheses.

**Shared alternate backgrounds and repeat reanchoring must compose.** A separate known-coordinate counterexample uses FASTA **`CAAAAAAA`**, one original row at position 1, REF **`CAA`**, ALT **`GA,GAAA,CAAAA`**, ID r. Source other/effect **`A/AAA` at known position 4** currently resolves to canonical position 1 `C:CAA`, beta +.625/EAF .137.

Yet there is a coherent ALT–ALT interpretation. Hold the shared alternate C→G background at position 1 fixed. In the resulting common background `GAAAAAAA`, replacing REF span `AA` at position 4 by `A` produces exactly the original `CAA -> GA` alternate haplotype; replacing the same `AA` span by `AAA` produces exactly the original `CAA -> GAAA` haplotype. These two source genotypes are both ALT relative to the original site. The third ALT `CAAAA` supplies the competing reference-background insertion of two As. Under the coordinator's shared-background policy, these are different measurements even though the observed allele-length difference can also describe that insertion.

The current literal signature scan cannot reach position 4 outside the original literal ALT span. Its fallback normalizes each ALT against the original genomic FASTA, so both event keys retain the shared G mutation; the local source-query events do not. Consequently the genuine pair is missed. A missing-position guard and complete ID closure do not fix this known-position composition. Exact input/output: `alternate-background-repeat/`. This is a deterministic composition of the two required guarantees, not a random stress observation.

**A conservative invariant is available without guessing more anchors.** If source allele lengths differ by D in absolute value, two original concrete ALT haplotypes can represent that source contrast only if their lengths also differ by D. Padding, reanchoring and removal of shared backgrounds preserve the difference of the two haplotype lengths. For D=0, require two distinct concrete ALT strings of the same length; duplicate strings/alias rows are not two alleles. Original REF must still be concrete and FASTA-valid, and each original context remains separate.

Therefore absence of a matching-length ALT pair proves ALT–ALT impossible within that eligible context. Presence of a pair is only a necessary condition, not a positive witness. If complete general pair equivalence has not been established, withholding complex generic measurements with such a potential pair is a scientifically safe conservative contract; a trusted source REF/ALT/strand contract can still select a genuine REF–ALT measurement. Known-coordinate biallelic indels and multiallelic contexts with no matching length difference need not be rejected by this particular invariant. The existing exact single-base path retains its finite signature proof. The coordinator must choose and document the contract before source implementation; this note does not silently broaden the normalizer.

**Further qualification and coordinator disposition.** The exact single-base ALT–ALT signature proof above assumes background removal does not change reference-to-alternate coordinate alignment. Allowing common background indels invalidates an unqualified anchor assertion. FASTA `AAAAAA`, source site position 1 REF `AA`, ALT `GCA,GCG,AG`, measured `A/G` at position 2 currently resolves to `A:G`. But the first two ALTs are the A/G contrast on the shared position-1 A→GC background, while AG is the reference-background SNP. The old inferred REF-span calculation gives zero for GCA/GCG and omits the competing background. Exact fixture: `singlebase-alternate-indel-background/`.

For single-base observations, an ALT–ALT contrast under any common background still requires two equal-length original ALT strings differing at exactly one base, with that differing base pair equal to the observed pair or its reverse complements. Their full alternate chromosomes differ at just that one character; identical source flanks cancel. This is a necessary condition independent of genomic anchor, and can be checked with a shared-prefix/suffix signature join. It is not by itself a positive placement/background witness. Ordinary noncompeting triallelic SNP contexts remain usable: A/G does not match the differing C/G ALT pair or its reverse complements.

The coordinator has now selected an explicit conservative implementation-7 contract covering shared background indels. Missing-position complex observations require coordinates. A selected generic canonical call that cannot exclude a potential ALT–ALT pair requires **`source_allele_context_required`**, with canonical identity/effect/EAF/flags withheld. Complex observations use the necessary allele-length-difference pair test; single-base observations use the sharper equal-length, one-base-difference pair condition. An eligible context with multiple distinct entries and unsupported/unknown ALT sequence or length is handled conservatively under that same context-required policy. Actual coherent competing witnesses remain proven ambiguity, rather than relabeling every necessary-condition match as proven ALT–ALT. Trusted source REF/ALT/strand handling is unchanged. All original rows remain retained. The final implementation and its precise status precedence/resource bounds still require a new frozen independent review.
