# Reviewed operator count toolkit

This is operator-only counting and logical planning, with no production admission
or build authority. The reviewed source is 306aea51ea45eb8ae781b339029d2b1b93b5388f;
its final scoped GREEN review permits only consideration of a separately reviewed,
explicitly admitted future count profile. Packaging executes no count/build/test.

Both expected publication roots must be independently supplied OUTSIDE profile
JSON. Missing context refuses. Profile/admission/case locations must be outside
both sources before content opens or mkdir. Both producer guards authenticate
before plans, receipts or artifact hashes; both complete producer seals precede
counted-input opens/hashes. Small source-plan/producer-guard controls require a
single link. Counted TSV/FASTA/alias data may have legitimate hardlinks without
copying. The coordinator creates no source-tree writes, index, .fai or native
writer output. Archived fixture profiles/probes are historical proof, not reusable
production authority; expected identities must come from reviewed producer context.

All no-admission fields remain permanent for this toolkit: decision=no_admission,
full_reference_admitted=false, index_builds_executed=0. Logical fit never authorizes
an index. Separate native build/memory/max-line/sort-buffer review, fresh free-space
measurement and post-first-build remeasurement remain necessary. No full-count
profile or admission is generated by this package.

The resource sampler is scoped to the synchronous known counting worker and its
native child while that worker remains alive. Historical receipt wording about a
process tree is not a production parent-exit/orphan-aware supervisor proof. That
separate lifetime proof is outside this archive (Task7). Limits remain 8GiB memory,
160GiB hard free floor, finite output/deadline caps and 170GiB planning reserve.
The sampler supports the reviewed macOS/Linux paths; no new Windows, whole-file,
peak-memory or speed qualification is supplied. The original 2.864s incomplete
prefix timing belongs to 1bf1a086 and excludes hashes; it is not a benchmark of the
later FAI scan/coordinator.

Runtime files are sealed_count.py, count_reference.cpp, guard_common.py and
process_memory.py. Python imports use the standard library and the co-located
sampler module; no pytest/bioDB import or provider client is needed to count.
The native counter requires the external exact MSS preservation_core.h and a
separately reviewed/pinned platform binary. The producer source is an external
identity artifact, not executed by this coordinator. dependencies.json records
those pins. No binary or production MSS header is vendored. COORDINATOR.md and
REVIEWED-README.md are exact source-era documentation, including historical
pending-review wording; the archive's final GREEN report records current review.
Proof scripts contain historical paths and are archival source, not launchers to
run over preserved evidence. No fixed prefix launcher is installed here.
