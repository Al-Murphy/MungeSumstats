## Findings

1. **Bind the selected SDK to the historical SDK pin.** The install argv and stderr checks use the receipt’s `toolchain.sdk`. The later check requires all historical pins and allows additional pins. Consequently a receipt can list both SDKs, select a different physical SDK, and pass the check because that second SDK’s `SDKSettings.json` also appears in the list. Compare the selected SDK settings path and digest directly with the historical `MacOSX27.2.sdk/SDKSettings.json` pin. The report promises that specific SDK. [Selected SDK and command](namespace-bench.py:139) [Pin validation](namespace-bench.py:193) [Input contract](NAMESPACE-BENCH-REPORT.md:32)

2. **Require each declared flag to appear in the captured R configuration.** `flags.get(key)` maps an absent key to `None`. A partially captured `R CMD config --all` and a receipt containing JSON `null` for that flag therefore agree. Require the six required names in the capture, require every declared key to exist there, and compare the captured strings directly. An explicitly captured empty string is a valid value. [Flag comparison](namespace-bench.py:200)
