# MungeSumstats key-page geometry benchmark

On the matched 1M-row workload, changing the key-page cache from **64 KiB × 128** to **16 KiB × 512** reduced median installed public API processing from **7.838 to 7.175 s (8.46% lower, 1.0924×)**. Processing was faster in all three pairs. Median whole-worker wall time fell from **11.686277 to 11.085536 s (5.14% lower)**. Median per-worker peak RSS was essentially unchanged (0.33% lower), while the maximum rose 0.91%. The baseline was `f39ab1b7f0a9fd643d70097e5764ba7e1fcf257b` and the candidate was `8b85aa5ffc45ad7632cfc5319e85dd5eb3089be6`. All 30 workers exited zero with complete peak RSS readings. The six editions in each case agreed on stable output bytes and stable RDS manifest data. Every tiny edition matched its literal TSV gold across all 19 fields. A fresh, independent post-timing oracle checked every field of all 1,000,000 rows in the measured first candidate edition with zero deltas. ## Profiling, counters and boundary tests

A separate profile of the baseline identified the lower-bound key-line read path in 514 of 3,446 sampled main-thread observations. The allocation profile and native sample were instrumented diagnostics outside the timed cohort. The production change keeps the key-page payload budget at 8 MiB per reference handle. The page container overhead can change. [Profile diagnosis](raw/mss-fullfile-20261121/runtime/CURRENT-MSS-PROFILE-DIAGNOSIS.md) · [Profiles observation](raw/mss-current-profiles-observation-20261121.json)

The native counter experiment retained exact outcomes, source tokens and float bits across roles on 32,768 distinct events in input and shuffled order. Key page reads increased from 4,746 to 7,032 in input order and from 73,336 to 78,265 when shuffled. Nominal key bytes requested by the application stream fell 62.96% and 73.32% respectively. Each miss requests one configured page and a final short page can return fewer bytes. Filesystem caching and buffering can change physical I/O independently. Both roles also passed format-2 and format-3 parity and pressure controls, plus format-3 newline, malformed-offset and UTF-8 boundary cases.
