# GenomicRanges to data.table

Convert a
[GRanges](https://rdrr.io/pkg/GenomicRanges/man/GRanges-class.html) into
a [data.table](https://rdrr.io/pkg/data.table/man/data.table.html).

## Usage

``` r
granges_to_dt(gr)
```

## Source

[Code adapted from
GenomicDistributions.](https://rdrr.io/github/databio/GenomicDistributions/src/R/utility.R)

## Arguments

- gr:

  A [GRanges](https://rdrr.io/pkg/GenomicRanges/man/GRanges-class.html)
  object.

## Value

A data.table object.
