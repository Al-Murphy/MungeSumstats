# List supported file formats

List supported file formats

## Usage

``` r
supported_suffixes(
  tabular = TRUE,
  tabular_compressed = TRUE,
  vcf = TRUE,
  vcf_compressed = TRUE
)
```

## Arguments

- tabular:

  Include tabular formats.

- tabular_compressed:

  Include compressed tabular formats.

- vcf:

  Include Variant Call Format.

- vcf_compressed:

  Include compressed Variant Call Format.

## Value

File formats
