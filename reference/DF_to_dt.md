# DataFrame to data.table

Efficiently convert
[DataFrame](https://rdrr.io/pkg/S4Vectors/man/DataFrame-class.html) to
[data.table](https://rdrr.io/pkg/data.table/man/data.table.html).

## Usage

``` r
DF_to_dt(DF)
```

## Source

[Solution from Bioc forum](https://support.bioconductor.org/p/66874/)

## Arguments

- DF:

  [DataFrame](https://rdrr.io/pkg/S4Vectors/man/DataFrame-class.html)
  object.

## Value

VCF data in data.table format.
