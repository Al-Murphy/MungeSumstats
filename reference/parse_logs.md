# Parse data from log files

Parses data from the log files generated by
[format_sumstats](https://al-murphy.github.io/MungeSumstats/reference/format_sumstats.md)
or
[import_sumstats](https://al-murphy.github.io/MungeSumstats/reference/import_sumstats.md)
when the argument `log_mungesumstats_msgs` is set to `TRUE`.

## Usage

``` r
parse_logs(
  save_dir = getwd(),
  pattern = "_log_msg.txt$",
  verbose = TRUE
)
```

## Arguments

- save_dir:

  Top-level directory to recursively search for log files within.

- pattern:

  Regex pattern to search for files with. Matches both the current
  `<save_path stem>_log_msg.txt` log names and the older
  `MungeSumstats_log_msg.txt` name.

- verbose:

  Print messages.

## Value

[data.table](https://rdrr.io/pkg/data.table/man/data.table.html) of
parsed log data.

## Examples

``` r
save_dir <- system.file("extdata",package = "MungeSumstats")
log_data <- MungeSumstats::parse_logs(save_dir = save_dir)
#> Parsing info from 1 log file(s).
```
