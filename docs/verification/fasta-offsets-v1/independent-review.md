## Reasoning

The stream is opened in binary mode. `std::getline` consumes one LF delimiter
and leaves any preceding CR in the string. Counting the original string bytes
plus one unless EOF was reached therefore reproduces physical line lengths.
The code counts before stripping CR, and preserves the start offset separately
before advancing the counter. An unterminated final line has EOF set after a
successful read, so no absent delimiter is counted. A final terminated line is
counted normally; the next empty failed read is discarded by the existing check.

The patch changes no contig-name, empty-line, duplicate-name, short-final-line,
or fixed-width validation. It does not change reference normalization, alias
resolution, allele direction, output formats, or reference lookup. The new code
uses portable C++17 stream operations and adds no platform API or dependency.

## Fresh independent checks

Compiled separate original and candidate C++ query drivers with
`clang++ -O2 -std=c++17`, each including its respective unchanged source header.
The driver saves FAI and reads sequences through `mss::Fasta::sequence`.

- **220 generated valid layouts**: original/candidate exit status, error output,
  FAI bytes, and sequence-query output were identical.
- Every valid FAI also matched an independently generated byte-offset oracle.
- **173,355 sequence queries** matched explicit source-sequence truth, covering
  all small positions, line/contig boundaries, zero lengths, ranges, out-of-range
  positions, and full-sequence reads.
- Cases include LF and CRLF, different uniform endings per contig, UTF-8 header
  descriptions, upper/lowercase DNA/IUPAC bytes, widths 1/2/3/4/7/31/80/128,
  short and full final lines, and one-line references with no final newline.
- **20 adversarial equivalence cases** matched exactly: 9 identical refusals and
  11 identical accepted outputs. These include missing/empty headers, missing
  initial header, duplicate names, blank lines, short interior lines, wider later
  lines, empty contigs, CR-only tails, embedded NUL/space sequence bytes, and
  nonuniform line endings.
- `git diff --check` passed. No source file was modified by the reviewer.

## Scope and existing behavior

This review does not claim a measured performance gain, full-genome index
completion, installed-package test success, or Windows execution. Those are
separate author/integration gates. The root author's new R test was inspected;
its reported 144 baseline assertions were not rerun by this reviewer.

The original parser can accept nonuniform LF/CRLF widths inside one contig,
although its fixed-width FAI cannot represent that layout correctly. The
candidate preserves this existing behavior exactly. This is outside the
documented fixed-line-width input contract, and is not introduced by this patch.
The production canonical FASTA producer emits consistent LF lines. Stronger
rejection of inconsistent physical line widths can be considered separately.

The reported installed namespace stack-imbalance warning occurs while loading
the package, before this constructor is called. This patch does not modify
namespace/import/loading code; this review makes no diagnosis or resolution
claim for that separate warning.
